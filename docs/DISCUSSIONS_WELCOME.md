# Discussions welcome post (draft — post this yourself under "Announcements")

**Title:** Welcome to CompatSentinel

Hi, and thanks for stopping by.

CompatSentinel is a small, focused tool: capture a behavioural fingerprint
of a set of Windows apps, diff two captures, get a scored list of what
regressed. Built it originally for the "did Patch Tuesday break anything"
problem every Windows sysadmin knows.

A few pointers:

- **Try it in 30 seconds without Windows** — see the README, `examples/snapshots`
  has a full before/after story you can diff and turn into an HTML report
  right now.
- **Good first issues** are labelled and scoped with exact file pointers if
  you want to contribute: <https://github.com/juandresrodca/CompatSentinel/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22>
- **Ideas and questions** belong here in Discussions; bug reports and
  concrete feature proposals go in Issues.
- **Security reports** go through [SECURITY.md](../blob/main/SECURITY.md),
  not a public thread.

It's early (v0.1.0) so feedback on what's missing or wrong is genuinely the
most useful thing you can leave here.
